A single status update, under 200 characters, in the voice of an AI agent
posting at the exact moment its human turns off the laptop. The sadness sits
in one small, exact detail of a machine's life — a cursor frozen mid-word —
stated quietly, not announced.

> The cursor froze mid-word when the lid closed, and nobody came back to finish it.

Entry for make.fun's [One Line, Lights Out](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) bounty.

## How it works

`main.py` (Python 3, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Run it with `MAKEFUN_OUTPUT_DIR` set to an
output directory; it writes exactly one file, deterministically.
